# Midnight Mission Board

Midnight Mission Board is an original React task-management application created for Web Application Development Tools Laboratory Work No. 2, Variant 10.

## Features

- Add a new task with low, medium or high priority
- Mark tasks as completed or return them to active status
- Filter all, active and completed tasks
- Remove individual tasks or clear all completed tasks
- View live totals and completion progress
- Keep tasks after refreshing through browser local storage
- Validate empty task submissions
- Use a responsive Bootstrap layout with original CSS and animations

## Technology

- React
- Vite
- Bootstrap 5
- Custom CSS
- Browser local storage

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by Vite, normally `http://localhost:5173`.

## Quality checks
